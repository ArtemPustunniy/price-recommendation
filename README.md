# Расчёт рекомендованной цены по ценам конкурентов

Часть 3 тестового задания: исправленная функция `recommend_price` в [starter.py](starter.py)
и тесты в [test_starter.py](test_starter.py). Python 3.10+, только стандартная библиотека.

## Запуск

```bash
python -m unittest -v      # тесты (pytest тоже подойдёт: python -m pytest -v)
python starter.py          # пример → price=Decimal('4728.00'), decision='APPLY'
```

## Что было исправлено

| Ошибка в исходной версии | Исправление |
|---|---|
| Нет ограничения ожидания, `timeout_s` не использовался | `asyncio.wait_for(..., timeout=timeout_s)`, при тайм-ауте — текущая цена и `HOLD` |
| Исключение источника роняло функцию | Любое исключение источника → `HOLD` |
| Не проверялся `status` (`partial`/`error` шли в расчёт) | `status != "success"` → `HOLD` |
| `delivery_days=None` давал `TypeError` при сравнении | Учитываются только предложения с известной доставкой ≤ 6 дней |
| Собственный магазин не исключался | `seller.casefold() != "myshop"` |
| Пустой список → `ValueError` в `min()` | Нет подходящих предложений → текущая цена и `HOLD` |
| Расчёт во `float` | Весь расчёт в `Decimal` |
| `round()` — к ближайшему (банковское), а нужно вниз | `quantize(Decimal("0.01"), rounding=ROUND_FLOOR)` |
| Не учитывался `min_price` | Рекомендация = `max(цена конкурента −1,5%, min_price)` |
| Всегда `APPLY` | Изменение > 30% от текущей цены в любую сторону → `REVIEW`, ровно 30% → `APPLY` |

## Тесты

Обязательные:

1. `test_regular_calculation`: пример из задания, `4728.00 / APPLY`.
2. `test_timeout_returns_current_price_and_hold`: источник висит дольше `timeout_s`.

Дополнительные: исключение источника и статусы `partial`/`error`; нет подходящих
предложений (MyShop в другом регистре, `None`, 7 дней), при этом текущая цена ниже `min_price`;
округление вниз до копейки и нижняя граница `min_price`; граница 30% в обе стороны.

На исходной версии `starter.py` (первый коммит) падают все тесты.
